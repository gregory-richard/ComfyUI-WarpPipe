# Warp Compare

Compare two images with a slider.

## Overview

**Warp Compare** shows two images on top of each other and lets you drag a slider to move between them. If you connect batches, the arrows step through the pairs: A1/B1, A2/B2, and so on. It replaces rgthree's image comparer in WarpPipe workflows.

## Inputs

Both inputs are **optional**:

- **image_a** — The first image (IMAGE).
- **image_b** — The second image (IMAGE).

## Output

None. This is an output node and shows the images as temporary previews.
