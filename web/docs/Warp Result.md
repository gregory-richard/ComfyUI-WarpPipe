# Warp Result

Collect the first and final images at the end of the hub.

## Overview

Put one **Warp Result** at the end of the hub. It takes the first and final images and shows them in the Warp Send that was active for that run, as a before/after slider.

## Inputs

All inputs are **optional**:

- **first** — The first generation (IMAGE).
- **final** — The final image (IMAGE).
- **target** — Set automatically: the name of the Send that shows the result.

## Output

None. This is an output node and queues the images as temporary previews.
